Drawx is an offline-first version of the planning and white boarding tool, serving as a variant of Drawy and Drawy Party.

Built with Tauri v2 and leveraging the Astryx UI framework by Meta, Drawx ensures a seamless user experience. Update distribution is managed via CrabNebula Cloud.

Binaries are available on [CrabNebula Cloud](https://web.crabnebula.cloud/pratyay/drawx), and the source code is available on GitHub.
