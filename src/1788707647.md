Drawx is an offline-first version of the planning tool Drawy and Drawy Party.

Built with Tauri v2 and leveraging the Astryx UI framework by Meta, Drawx ensures a user experience similar to drawy but in an offline setup. 

Updates are managed via Crab Nebula Cloud.

Binaries are available on [CrabNebula Cloud](https://web.crabnebula.cloud/pratyay/drawx), and the source code is available on [GitHub.](https://github.com/Pratyay360/drawx)
